# Laksh Yadav – Portfolio

Single-page portfolio built with plain HTML, CSS and JavaScript (no build step).

- Hero with a cut-out avatar whose eyes follow the cursor or finger, and a 3D ring of the name that spins around the face
- Projects: WatchWise, SwaraVeda (with demo video), Cloud Resource Allocation
- Education, certificates and a downloadable resume

## Files
- `index.html` – the site
- `swaraveda-demo.mp4` – SwaraVeda demo clip
- `Laksh_Yadav_Resume.pdf` – resume download

## Run locally
Open `index.html` in a browser.

## Deploy
Import this repository in Vercel (Framework preset: Other). No build command or output directory is needed.
