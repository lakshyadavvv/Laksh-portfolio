02
Course final project · AI for culture

SwaraVeda

Live Project

What it does. A community archive where people record, transcribe with AI, correct and preserve endangered dialects.

Co-developed as the final project of a 7-week AI course. People record or upload a voice, AI writes a timestamped first draft with a suggested English translation, native speakers correct it, and verifiers approve it. Dialects sit on a shelf you can browse by region.

Speech processingNLPDigital humanitiesVercel

What I learned: how AI speech tools, human review and a simple web interface can work together to preserve spoken languages.

03
Team project · Algorithms

Cloud Resource Allocation

Live ProjectRepo

What it does. Picks the best use of limited CPU, memory and storage for a cloud budget.

Modelled the problem as a 0/1 Knapsack and solved it with Dynamic Programming, which checks every combination and guarantees the best allocation. Includes an interactive page to set a budget, add tasks and run the solver.

PythonDynamic ProgrammingJavaScriptHTMLCSS

What I learned: how to turn a real problem into an algorithm, and why Dynamic Programming beats a greedy approach when you need the best answer.
